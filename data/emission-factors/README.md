# Emission Factors Data

This folder will hold:

- seed files for common industrial fuels
- region-specific electricity emission factors
- process-specific factors for target sectors
- source references and validity dates

Suggested first datasets:

- natural gas
- diesel
- fuel oil
- LPG
- standard electricity factors by geography

Every factor record should include:

- factor name
- category
- quantity unit basis
- factor value
- geography or scope
- source reference
- valid from and valid to
